# Import EMMET dans Claude Code

1. Extraire cette archive dans un dossier emmet-city indépendant de STREETZ.
2. Lire EMMET_DOSSIER_REPRISE_CLAUDE_CODE.md et son brief final.
3. Lancer npm test puis npm run build.
4. Servir dist avec un serveur HTTP (par exemple python3 -m http.server 8000 --directory dist).
5. Initialiser ou raccorder le dépôt Git de destination ; l’historique Git et les accès hébergeur ne sont pas inclus.

Cette archive contient les sources V03, les tests et la documentation, sans dépendance npm déclarée.
La démo hébergée n’est pas un backend à reproduire : le jeu est statique et solo.
Ne pas éditer dist ; modifier web puis reconstruire.
La référence SHA est celle du dépôt d’origine, pas un commit présent dans cette archive.
Les captures docs/images sont historiques et ne prouvent pas les performances.
